# Machine Monitor integration 1.4.1

Исправлена потеря машины в обзоре при одновременном запуске нескольких записей интеграции: инициализация общего координатора теперь защищена одним asyncio.Lock. WebSocket API и все записи используют один координатор.

Проверки: 105 Python integration tests, 45 frontend tests; JavaScript syntax и Python AST. До исправления новый concurrent startup test воспроизводил создание двух координаторов.

Прошивка, MQTT, physical/semantic history, статистика и отрисовка Real Flow не изменены. Схема истории остаётся 4. Установка: сохранить резервную копию, распаковать integration ZIP в /config, перезапустить Home Assistant. Перепрошивка ESP32 не требуется. Обновление страницы браузера достаточно; JS не изменён.

Откат на 1.4.0 совместим по схеме истории, но возвращает гонку запуска. Для отката на версии со схемой 3 требуется согласованная резервная копия профиля/истории и конфигурации.

Ограничения: тесты используют HA/DOM boundaries. Работа двух машин после перезапуска реального HA проверяется отдельно. Временная «Ошибка конфигурации» Lovelace на действующей установке исчезла после refresh, консоль не предоставила причины; полное устранение этого отдельного симптома пока не подтверждено.
