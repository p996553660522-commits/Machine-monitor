# Machine Monitor integration 1.4.2

Убрана стандартная подсказка браузера, появлявшаяся поверх оформленной подсказки Real Flow при долгом наведении. Текст физических интервалов, OFFLINE и названий строк теперь хранится отдельно от HTML title. aria-label сохраняет сведения для средств доступности. Работают мышь, касание, Enter/Space, Escape и клавиатурный фокус; вложенные элементы названия строки также открывают подсказку.

Проверки: 105 Python integration tests, 47 frontend tests (включая два новых сценария detailed/compact, OFFLINE, скрытые строки, клавиатуру и очистку подсказки), 9 release tests, JS syntax. Локальные тесты используют HA/DOM boundaries; визуальная проверка на реальном HA выполняется отдельно.

Backend monitoring, история, статистика, MQTT и firmware не изменены. Схема истории остаётся 4.

Установка: сохранить резервную копию файлов интеграции, перенести содержимое custom_components/machine_monitor из integration ZIP в /config/custom_components/machine_monitor, перезапустить HA для регистрации нового frontend resource hash и обновить вкладку браузера. Перепрошивка ESP32 не требуется. Откат на 1.4.1 совместим по схеме данных; старые опубликованные теги/архивы сохранены. Возврат на схему 3 требует согласованной резервной копии профиля/истории и конфигурации.
