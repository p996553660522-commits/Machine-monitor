# ESP32 firmware 1.2.2 — настраиваемый MQTT-брокер

Веб-конфигуратор получил поле **MQTT broker address / Адрес MQTT-брокера**. Для сети второго завода укажите `192.168.0.22`; порт остаётся 1883. Допустим IPv4 или ASCII DNS-имя без схемы URL, порта и пути. IPv4 используется напрямую без DNS/mDNS. Адрес сохраняется в NVS, пустое поле означает прежний `homeassistant.local`.

Устройства без нового NVS-ключа продолжают использовать прежний адрес. Неверный ввод отклоняется HTTP 400 до записи настроек и reboot. Исправлена проверка DNS: только успешный результат и ненулевой IP считаются найденным broker.

Сохранены все прежние функции: GPIO32/33/25/26, LOW=ON, debounce, переключатели линий, deviceId и discovery identities, topics, availability, HA birth, Wi-Fi recovery/fallback AP и настройки. HA-интеграция 1.4.0, история и роутеры не меняются. OTA не добавлялась.

## Установка

Скачайте firmware ZIP и SHA256SUMS. Распакуйте **всю** папку firmware/MachineMonitor: BrokerAddress.h должен находиться рядом с MachineMonitor.ino. В Arduino IDE выберите свою ESP32-плату, ESP32 core и PubSubClient; выполните Verify/Upload по USB. Чтобы сохранить настройки, не очищайте всю Flash и сохраните прежнюю разметку разделов.

После запуска откройте страницу ESP32 (для второго завода 192.168.1.102, если DHCP-адрес сохранился), введите MQTT broker address `192.168.0.22`, проверьте MQTT username/password и нажмите Save and reboot. Ожидается MQTT CONNECTED при доступном broker TCP 1883 и корректных credentials.

При откате на 1.2.1 старый код игнорирует новый NVS-ключ и использует homeassistant.local. MQTT protocol не менялся. Прошивка остаётся наблюдательной.

## Проверки и границы

Семь firmware tests: сохранение legacy-функций, настройки/default, подключение поля и проверка ошибки до сохранения, compile-time C++ cases валидатора, startup ordering. C++ проверки выполняются компилятором, а не эмуляцией алгоритма в Python. Полная сборка ESP32 Dev Module прошла: ESP32 core 3.3.11, PubSubClient 2.8; flash 978592 / 1310720 bytes (74%), globals 49832 / 327680 bytes (15%). фактическая работа на плате/через VPN требует приёмки после USB-загрузки. Автоматической загрузки на устройство не выполнялось.
