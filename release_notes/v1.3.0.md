# Machine Monitor 1.3.0 — архивная версия

Необязательные привязки 1–4 входов, acquisition_enabled, корректное отключение линий без ложного OFFLINE, сохранение истории и live updates. Схема истории 3.

Выбран последний снимок 1.3.0 с прошивкой **1.2.1**, содержащей исправление первого запуска ESP32. Первоначальный снимок с firmware 1.2 доступен отдельно как firmware-v1.2.0 с предупреждением.

**Известное ограничение:** старое имя ColorSelector в настройках входа несовместимо с актуальным HA; исправлено в 1.4.0. Исторические проверки: 97 Python / 37 frontend tests, firmware build ESP32 core 3.3.11 + PubSubClient 2.8. Повторная проверка снимка выполняется при упаковке; аппаратная проверка не подразумевается.

## Установка и откат

Скачайте подходящий ZIP из Assets и SHA256SUMS.txt. Архив integration содержит `custom_components/machine_monitor`; только эту папку копируйте в HA. Архив firmware содержит исходный Arduino sketch, его нужно собрать для своей платы. Полный source ZIP — для разработки.

Перед обновлением сохраните HA backup с конфигурацией, `.storage` и текущей папкой интеграции. Перезапустите HA после замены интеграции, затем обновите браузер. При откате используйте инструкции `INSTALL_RU.md` из этого релиза и совместимую резервную копию данных. Профили/история и пароли пользователя в публичные архивы не входят.
