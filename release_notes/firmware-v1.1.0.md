# ESP32 firmware 1.1 — архивная версия

Первоначальный опубликованный скетч: четыре физических входа GPIO32/33/25/26, INPUT_PULLUP, LOW = active, MQTT Discovery. Переключателей отключения линий ещё нет.

Тег использует нормализованный номер 1.1.0, строка версии оригинальной прошивки остаётся 1.1. Скетч сохранён без изменений. Собирается в Arduino IDE с ESP32 board support и PubSubClient. Готовый бинарник не прилагается: настройки платы и библиотек нужно выбрать под своё устройство.

## Установка и откат

Скачайте подходящий ZIP из Assets и SHA256SUMS.txt. Архив integration содержит `custom_components/machine_monitor`; только эту папку копируйте в HA. Архив firmware содержит исходный Arduino sketch, его нужно собрать для своей платы. Полный source ZIP — для разработки.

Перед обновлением сохраните HA backup с конфигурацией, `.storage` и текущей папкой интеграции. Перезапустите HA после замены интеграции, затем обновите браузер. При откате используйте инструкции `INSTALL_RU.md` из этого релиза и совместимую резервную копию данных. Профили/история и пароли пользователя в публичные архивы не входят.
