# Machine Monitor 1.4.0

- Универсальные названия режимов и условия И/ИЛИ, приоритеты.
- Продуктивный / непродуктивный / исключённый учёт независимо от категории.
- Сохранение учёта вместе с семантическими интервалами; изменения действуют на будущее.
- Визуальная группировка разрывов меньше 10 секунд с точным режимом, без изменения истории и статистики.
- Исправлены RGB selector и сортировка событий с разными UTC offsets.

Схема истории **4**; безопасно читает 1–3. При возврате к старому коду требуется соответствующая резервная копия профилей/истории. Физическая история, OFFLINE и быстрые event-driven обновления сохранены. Прошивка 1.2.1 не менялась.

Проверено: 104 Python / 44 frontend tests, 2 firmware source guards, syntax/import/JSON. Эти проверки не заменяют приёмку в живом HA.

## Установка и откат

Скачайте подходящий ZIP из Assets и SHA256SUMS.txt. Архив integration содержит `custom_components/machine_monitor`; только эту папку копируйте в HA. Архив firmware содержит исходный Arduino sketch, его нужно собрать для своей платы. Полный source ZIP — для разработки.

Перед обновлением сохраните HA backup с конфигурацией, `.storage` и текущей папкой интеграции. Перезапустите HA после замены интеграции, затем обновите браузер. При откате используйте инструкции `INSTALL_RU.md` из этого релиза и совместимую резервную копию данных. Профили/история и пароли пользователя в публичные архивы не входят.
