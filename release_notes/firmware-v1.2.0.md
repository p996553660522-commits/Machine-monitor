# ESP32 firmware 1.2 — известная ошибка, только архив

Добавлены сохраняемые переключатели включения каждого входа, availability и acquisition_enabled.

**НЕ РЕКОМЕНДУЕТСЯ ДЛЯ УСТАНОВКИ.** На первом запуске без Wi-Fi настроек возможен assert xQueueSemaphoreTake: HTTP server запускался до инициализации сети. Используйте firmware-v1.2.1. Этот prerelease сохранён для воспроизводимости и анализа; скетч не исправлялся задним числом.

Исторически компилировалась с ESP32 core 3.3.11 и PubSubClient 2.8. Компиляция не гарантирует успешный запуск. Тег 1.2.0 соответствует оригинальной строке версии 1.2.

## Установка и откат

Скачайте подходящий ZIP из Assets и SHA256SUMS.txt. Архив integration содержит `custom_components/machine_monitor`; только эту папку копируйте в HA. Архив firmware содержит исходный Arduino sketch, его нужно собрать для своей платы. Полный source ZIP — для разработки.

Перед обновлением сохраните HA backup с конфигурацией, `.storage` и текущей папкой интеграции. Перезапустите HA после замены интеграции, затем обновите браузер. При откате используйте инструкции `INSTALL_RU.md` из этого релиза и совместимую резервную копию данных. Профили/история и пароли пользователя в публичные архивы не входят.
