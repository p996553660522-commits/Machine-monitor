# Установка и обновление

## Что потребуется

- Home Assistant с доступом к каталогу `/config` и работающей интеграцией MQTT.
- MQTT broker, доступный ESP32 и Home Assistant. Для штатного скетча — `homeassistant.local:1883`.
- ESP32 с прошивкой из этого репозитория или другие доступные HA binary sensors для источников.

Минимальная версия Home Assistant пока не заявлена: точная матрица совместимости требует отдельной проверки. Это custom integration, а не компонент HA Core. Установка через HACS в текущем руководстве не заявлена.

## 1. Получить файлы

На странице GitHub выберите **Code → Download ZIP**, распакуйте архив. Либо выполните:

```sh
git clone https://github.com/p996553660522-commits/Machine-monitor.git
```

## 2. Установить интеграцию

Скопируйте папку `custom_components/machine_monitor` из репозитория в `/config/custom_components/machine_monitor`.

Ожидаемая структура:

```text
/config/custom_components/machine_monitor/__init__.py
/config/custom_components/machine_monitor/manifest.json
/config/custom_components/machine_monitor/frontend/machine_monitor_card.js
/config/custom_components/machine_monitor/translations/ru.json
```

Не должно быть дополнительного уровня `machine_monitor/machine_monitor`. Firmware и docs в папку интеграции копировать не требуется. Перезапустите Home Assistant.

## 3. Проверить источники

Прошейте и настройте устройство по [руководству ESP32](FIRMWARE_RU.md). В **Настройки → Устройства и службы → MQTT** найдите устройство и четыре binary sensors. Убедитесь, что реальное переключение входа меняет состояние нужного sensor.

Диагностические entities, созданные самой Machine Monitor, нельзя выбирать как исходные входы. Источник должен быть исходным MQTT sensor или другим внешним binary sensor.

## 4. Добавить машину

**Настройки → Устройства и службы → Добавить интеграцию → Machine Monitor**. Введите название машины и выберите источники четырёх входов. Для следующей машины добавьте ещё одну запись интеграции.

Откройте **Настроить** у соответствующей записи. Меню позволяет настроить каждый вход и общие параметры машины. Подробнее — [руководство пользователя](MANUAL_RU.md).

## 5. Открыть UI

Обновите страницу браузера. В боковом меню нажмите **Machine Monitor**, затем выберите машину. Здесь есть мониторинг, Real Flow, отчёты и диагностика. JS обслуживается интеграцией: копирование в `/www` и ручная регистрация resource не нужны.

Для отдельной карточки: **свой Dashboard → Редактировать → Добавить карточку → Machine Monitor → выбрать машину → Сохранить**. Полная версия карточки называется **Machine Monitor — Full UI / Полный интерфейс**. Редактор отдельной карточки задаёт машину, период, compact/detailed и показ статуса, итогов и OFFLINE.

Готовая панель интеграции использует её `dashboard.yaml`. Если путь `/machine-monitor` уже занят пользовательской панелью, интеграция сохраняет её: используйте Add Card на своей панели и проверьте предупреждение в журнале.

## Обновление

1. Сделайте резервную копию Home Assistant с его `/config/.storage` и настройками.
2. Замените файлы `/config/custom_components/machine_monitor` файлами новой версии. Данные хранятся отдельно от исходников; не удаляйте `.storage`.
3. Перезапустите Home Assistant и обновите вкладку браузера, при необходимости Ctrl+F5.
4. Проверьте текущие состояния, имена и Diagnostics → History Storage.

URL frontend автоматически содержит hash содержимого JS. История использует schema 3 с совместимым чтением прежних schema 1/2. Старые semantic-only данные не превращаются в выдуманную physical history: физические интервалы начинаются с момента их фактического сбора.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Интеграция не находится | Расположение `manifest.json`, перезапуск HA, журналы `machine_monitor` |
| Устройство ESP32 не появилось | Wi-Fi, адрес broker, MQTT login, MQTT Discovery, Serial Monitor |
| Входы в HA unavailable | Связь ESP32 с broker, availability topic, LWT и журналы MQTT |
| Есть entities, нет UI | Обновить браузер; боковая панель или Add Card; журналы регистрации frontend |
| Все входы скрыты | Real Flow → фильтры → Все |
| Нет старой истории | Срок хранения, дата первой записи, разница physical и semantic history |
| Состояние неожиданное | Настройки входов, приоритеты, активные сигналы и диагностика источников |
| Не работает `.local` | Локальное разрешение имени/mDNS; используйте фактический IP устройства для его страницы |

Не публикуйте пароли, полные домашние HA backups и raw `.storage` при создании issue. Для ошибки достаточно версии, сценария, обезличенного фрагмента журнала и ожидаемого/фактического результата.
