## Что лежит в релизе

- Integration ZIP: папка `custom_components/machine_monitor` без тестов и приватных данных плюс инструкции и metadata.
- Firmware ZIP: точный Arduino sketch и руководство.
- Source ZIP: полный публичный исходный снимок с тестами и документацией.
- `SHA256SUMS.txt`: контрольные суммы ZIP.
- `release.json`: версия, точный commit, схема истории и сопряжённая firmware.
- `RELEASE_NOTES.md`: изменения, проверки и известные ограничения.

Для проверки в PowerShell: `Get-FileHash -Algorithm SHA256 .\machine-monitor-1.4.0.zip`. Сравните результат с SHA256SUMS.

## Установка

Сначала сохраните полный HA backup с конфигурацией и `.storage`. Распакуйте integration ZIP и перенесите только `custom_components/machine_monitor` в `/config/custom_components/machine_monitor`. Перезапустите HA и обновите браузер. Копировать JS в `/www` не нужно. История и ваши профили в установочный ZIP не входят.

## Откат

Снимок кода не заменяет резервную копию данных. Схема 4 читается новой интеграцией, но не старыми 1.2.2/1.3.0. Для возврата восстановите согласованный HA backup **до** обновления: конфигурацию записи интеграции, profile store, history stores и старую папку компонента. Сохраните также backup нового состояния перед возвратом, чтобы не потерять накопленную после обновления историю.

Если делаете восстановление только Machine Monitor вручную, HA должен быть остановлен: восстановите его записи интеграции вместе с `machine_monitor.profiles` и соответствующими `machine_monitor.<entry_id>` файлами в `.storage`, не затрагивая остальные интеграции. Без согласованной копии config entries/entry IDs профиль и история могут не привязаться. Предпочтителен штатный HA backup/restore.

Не меняйте номер схемы в JSON и не удаляйте историю для обхода ошибки. Старые записи не превращаются в фиктивные физические интервалы. Не понижайте firmware одновременно с интеграцией без необходимости.

## Сохранность

Теги привязаны к полным SHA и не перемещаются. Автопубликация не заменяет опубликованные assets: несовпадение тега/контрольной суммы останавливает процесс. Для исправления выпустите следующий номер версии. Версии до 1.2.2 не представлены полноценным опубликованным исходным снимком; обещать их установку нельзя.
